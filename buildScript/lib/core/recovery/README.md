# Staged sysctl write-ahead journal
This isolated Linux module stores only per-interface sysctl restoration intent, not credentials, firewall commands, TC programs or PID-based kill commands. Use the validated state-store directory fd and exclusive supervisor ownership. File publication is write, fsync, rename and directory fsync; malformed or foreign files fail closed. Scope is boot ID plus network namespace identity. The loader never restores any value itself.

Not linked into normal builds yet. Before activation: record intent before every actual sysctl mutation and remove records only after verified rollback; recover only after exclusive listener acquisition, verified absence of the previous children, and native owned-resource reconciliation. Compare live interface identity and current value, never restore global all/default or a replacement link; if ownership is uncertain, report it instead. A matching name and ifindex alone does not eliminate reuse within one boot. Do not recreate Android netd-owned offload filters. Run `bash buildScript/test/root_sysctl_wal.sh` on a Linux host.
